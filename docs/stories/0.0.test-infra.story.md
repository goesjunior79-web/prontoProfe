## Goal

Configurar Vitest como test runner do projeto. Criar estrutura `__tests__/`
separada de `lib/`, script `npm test` funcional, e 1 teste smoke passando.

## Context

A FASE 0 (Bedrock) tem 4 stories que dependem de infraestrutura de testes funcionando:
US-002 (Validador determinístico) e US-003 (Pipeline G+C) precisam validar com testes
unitários antes de mergear.

Vitest foi escolhido (vs Jest) por:
- Mais leve (≤30s instalação)
- Compatível com Next.js sem ajustes pesados
- Sintaxe Jest-compatible — fácil migração futura se necessário
- Suporte ESM nativo

Sem CI no MVP — testes rodam localmente, validados por `@qa` antes do merge.
