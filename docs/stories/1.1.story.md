# Story 1.1 — Exportar conteúdo gerado para PDF, Word ou Excel

## Status
Done

## Story

**Como** professor,  
**quero** exportar o conteúdo gerado pela IA para PDF, Word ou Excel,  
**para que** eu possa imprimir, compartilhar ou arquivar o material de forma profissional, seguindo um modelo padronizado.

---

## Contexto

O projeto **Pronto Profe** é uma aplicação Next.js que permite ao professor enviar um prompt e receber conteúdo gerado por IA (Claude, Gemini, etc.). Após a resposta aparecer na tela, o professor precisa de uma forma rápida de exportar esse conteúdo em um formato editável ou imprimível.

A exportação deve ocorrer inteiramente no lado do cliente (sem chamadas adicionais ao servidor), seguindo um **modelo/template visual padronizado** para cada formato (cabeçalho com nome da escola, data, rodapé).

---

## Acceptance Criteria

- [ ] AC1: Após a IA retornar uma resposta, aparecem 3 botões de exportação: **PDF**, **Word** e **Excel**.
- [ ] AC2: Ao clicar em **PDF**, o conteúdo é exportado como `.pdf` usando `pdf-lib` (já instalada), com modelo que inclui cabeçalho (logo/título "Pronto Profe"), data de geração e rodapé.
- [ ] AC3: Ao clicar em **Word**, o conteúdo é exportado como `.docx` usando a lib `docx`, com o mesmo modelo (cabeçalho e rodapé).
- [ ] AC4: Ao clicar em **Excel**, o conteúdo é exportado como `.xlsx` usando a lib `xlsx` (SheetJS), com o conteúdo estruturado em células (linha de cabeçalho + conteúdo).
- [ ] AC5: O nome do arquivo exportado segue o padrão `pronto-profe-YYYY-MM-DD.{ext}`.
- [ ] AC6: Os botões de exportação ficam **desabilitados** enquanto a IA está gerando a resposta.
- [ ] AC7: Se o conteúdo estiver vazio, os botões não aparecem.
- [ ] AC8: A exportação não faz nenhuma requisição adicional ao servidor.
- [ ] AC9: Funciona nos navegadores Chrome, Firefox e Edge (últimas versões).

## Modelo de Documento (Template)

Cada arquivo exportado deve seguir este modelo:

```
┌─────────────────────────────────────────┐
│  PRONTO PROFE — Assistente do Professor │
│  Data: DD/MM/YYYY          Hora: HH:MM  │
├─────────────────────────────────────────┤
│                                         │
│  [Conteúdo gerado pela IA]              │
│                                         │
├─────────────────────────────────────────┤
│  Gerado por IA · Provedor: {provider}   │
│  Modelo: {model}                        │
└─────────────────────────────────────────┘
```

## Notas Técnicas

| Formato | Biblioteca      | Status deps    | Observação                          |
|---------|----------------|---------------|-------------------------------------|
| PDF     | `pdf-lib`       | ✅ já instalada | Usar `PDFDocument`, fontes embutidas |
| Word    | `docx`          | ⬜ instalar     | Gera `.docx` puro no browser        |
| Excel   | `xlsx` (SheetJS)| ⬜ instalar     | Gera `.xlsx` com `XLSX.utils`       |

**Geração client-side:** usar `URL.createObjectURL(blob)` + `<a download>` para trigger do download sem servidor.
