# Story 3.1 — Painel N1-N4 + Classificador (US-011a + US-011b)

> **Epic:** EPIC-3 (Telas por aluno)
> **Status:** Done

## Goal

Tela `/painel` mostra alunos da turma classificados em N1-N4 com observação +
intervenção. Engine LLM (PROMPT 8) gera classificação JSON estruturada.

## Stories cobertas
- US-011a — UI do Painel
- US-011b — Pipeline JSON estruturado para PROMPT 8

## File List
- `pages/painel.js` (novo) — UI tabela + filtros + toggle cores
- `pages/api/painel/classificar.js` (novo) — endpoint classifier
- `lib/db/avaliacoes.js` (novo) — CRUD em avaliacoes (createAvaliacao, listAvaliacoesByAluno, getLatestByAluno)

## Decisões

### Cores
- Padrão: N1 azul / N2 verde / N3 amarelo / N4 vermelho (decisão Sheila)
- Toggle "Semáforo": N1 vermelho / N2 amarelo / N3 verde claro / N4 verde escuro
- Persiste em `localStorage.sesi_cfg.modoCores`

### Pipeline classificador
Diferente do pipeline geral (Generator + Critic), o classificador pede **JSON
estruturado direto** no system prompt e parseia. Validador determinístico
verifica:
- Nivel ∈ N1-N4
- Intervenção do catálogo fechado (4 valores) — auto-fix se LLM inventar

### Persistência
Cada classificação é salva em `avaliacoes` com `fonte='classificador_llm'`.
Histórico longitudinal alimenta US-010 (Relatório de Etapa).
