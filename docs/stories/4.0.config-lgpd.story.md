# Story 4.0 — Tela /config + LGPD export/delete (US-013)

> **Epic:** EPIC-4 (Polimento)
> **Status:** Done

## Goal

Tela `/config` para a professora gerenciar perfil, horário fixo, modo de cores e
direitos LGPD (exportar dados / excluir conta). Substitui o `ConfigModal` legado.

## Stories cobertas
- US-013 — Tela Configurações + Upload assets

## File List
- `pages/config.js` (novo) — Tela Configurações
- `pages/api/me/index.js` (novo) — GET preferências, PUT update, DELETE conta (LGPD esquecimento)
- `pages/api/me/export.js` (novo) — GET exporta dados (LGPD portabilidade)
- `pages/api/assets/upload.js` (novo) — POST upload de asset institucional → bucket `user-assets`
- `lib/db/users.js` (estendido) — `deleteAccount(userId)` cascade soft-delete
- `lib/db/export.js` (novo) — `exportUserData(userId)` → JSON consolidado

## Decisões

### Horário fixo
Persistido em `usuarios.preferencias` (JSONB) como `{ horarioSemanal: "seg 2, ter 2, ..." }`.
Lido pelo PROMPT 6 (Aula Diária / Semanário).

### Modo de cores
Persistido em `localStorage.sesi_cfg.modoCores` **e** sincronizado com
`usuarios.preferencias.modoCores` (server-side fallback caso o usuário troque
de dispositivo).

### Upload de assets
Vai pra `user-assets` bucket (privado, só service_role). Path:
`{userId}/{assetKey}.{ext}`. Substitui asset existente (overwrite).
US-014b cobre detecção dinâmica do registry com esse bucket.

### LGPD — Direito à portabilidade
GET `/api/me/export` — retorna JSON com **todos** os dados do usuário:
perfil, alunos (com obs_nee descriptografada), planejamentos, avaliações,
acessos_dados (audit log) — tudo numa estrutura única para download.

### LGPD — Direito ao esquecimento
DELETE `/api/me` — soft-delete cascata (deleted_at = NOW()) em:
- usuarios
- alunos
- planejamentos
- avaliacoes

Hard delete em 30 dias por job futuro (não escopo do MVP).
Audit log preservado (compliance).
