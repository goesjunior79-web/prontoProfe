## Decisões

### US-014b — Detecção dinâmica
Quando `userId` está disponível (sessão), `checkAssetWithUploads` busca arquivos
em `user-assets/{userId}/{assetKey}.*`. Filesystem (`docs/assets-esposa/`) tem
prioridade — se o asset institucional global existir, ele vence o upload do
usuário. Isso permite atualizar o asset central sem invalidar uploads.

### US-015 — Autorização admin via env
Sem RBAC formal, admin é qualquer email em `ADMIN_EMAILS=goesjunior79@gmail.com,...`.
Fail-closed (sem env → ninguém é admin). Suficiente para 1-2 admins no MVP.

### US-016 — Cache hit rate
Fórmula: `cache_read_input_tokens / (input_tokens + cache_creation + cache_read)`.
- 0 = nada cacheado (cold start)
- 1 = tudo veio de cache (mesmo prompt repetido em < 5min)
- ~0.6+ = saudável quando há paralelismo de gerações da mesma professora

Persistido em `planejamentos.cache_hit_rate` quando o cliente passa o campo no save.
