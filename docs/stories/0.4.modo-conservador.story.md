## Goal

Implementar registry de assets institucionais com detecção de presença/ausência
em filesystem. Quando assets faltam, app entra em "modo conservador":
- Avisa a usuária via banner UI (`AssetWarningBanner`)
- Backend pode adaptar output (omitir vs inventar)

## UI do banner

Banner dismissable com 3 cores por severity (vermelho/amarelo/azul). Pode ser
filtrado por tipo de output (ex.: tela de Avaliação só mostra missing relevantes
para Avaliação).

```jsx
<AssetWarningBanner tipo="simulado" onDismiss={() => {}} />
```
