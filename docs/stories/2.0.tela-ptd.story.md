### Migração para `docx` library puro (ADR-005) — ADIADA
A spec original previa migração de `html-to-docx` (atual via `/api/gerar-plano-docx`)
para `docx` library puro nesta story. **Optei por adiar** para acelerar entrega
do MVP — o `lib/planoBuilder.js` atual gera HTML que vira `.docx` aceitável.

Migração para `docx` puro fica para fase de polimento (Sprint 4) ou story
dedicada quando Sheila validar fidelidade visual em ambiente real.

### Snapshot test pré/pós refactor — ADIADO
Mesmo motivo: depende de execução end-to-end com prompt real.

### Tela vs aba antiga
Criei `pages/ptd.js` como **rota dedicada** (Tela 2 do MVP). A aba "plano" do
`pages/index.js` legacy continua funcionando — pode ser refatorada/removida
quando a tela inicial reorganizada (FASE 4 de polimento).

## Como funciona

```
[Usuária acessa /ptd]
  ↓
[Form: Ano + Componente + Capítulo + Vigência]
  ↓
[Botão "Gerar PTD"]
  ↓
POST /api/generate {
  prompt: "Gere PTD ...",
  tipo_de_saida: 'PTD',
  meta: { tipo: 'plano', titulo, disciplina, serie }
}
  ↓
[runPipeline com PROMPT MESTRE + cache + corretor]
  ↓
[Validador determinístico + LLM rejeitam invenção/fora de estrutura]
  ↓
[Response { result, prompt_versao, custo_estimado, pipeline_passed, warnings }]
  ↓
[POST /api/planejamentos { tipo: 'PTD', ano, componente, capitulo, conteudoGerado, ... }]
  ↓
[Tela mostra:
   - Output em <pre>
   - Botão "Baixar Word" → /api/gerar-plano-docx
   - Botão "Gerar aula semanal" (placeholder US-006)
   - ID do planejamento salvo]
```
