# Story 1.2 — Salvar conteúdo gerado direto na nuvem (Google Drive / OneDrive)

## Status
Done

## Story

**Como** professor,  
**quero** salvar o conteúdo gerado pela IA diretamente no Google Drive ou OneDrive,  
**para que** eu tenha meus materiais organizados na nuvem institucional, sem precisar baixar e fazer upload manualmente.

---

## Contexto

Extensão da Story 1.1 (exportação local). Após a IA gerar uma resposta, além dos botões de download local, o professor verá botões para salvar direto na nuvem. A pasta **"Pronto Profe"** é criada automaticamente no primeiro uso, com subpastas organizadas por **mês/ano** para facilitar a localização posterior.

Estrutura de pastas gerada automaticamente:
```
Pronto Profe/
  └── Abril 2026/
      ├── pronto-profe-2026-04-15.pdf
      ├── pronto-profe-2026-04-15.docx
      └── pronto-profe-2026-04-15.xlsx
```

Ambas as integrações usam autenticação OAuth2 com conta institucional (Google Workspace / Microsoft 365). A autorização é solicitada uma única vez; o token é mantido na sessão do browser.

---

## Acceptance Criteria

- [ ] AC1: Após a IA responder, aparecem 2 botões de nuvem: **"Salvar no Drive"** e **"Salvar no OneDrive"**, além dos botões de download local (story 1.1).
- [ ] AC2: Ao clicar em qualquer botão de nuvem, se o professor ainda não estiver autenticado, abre popup de login OAuth2 com a conta institucional.
- [ ] AC3: Após autenticação, o professor escolhe o formato (PDF, Word ou Excel) antes de salvar — ou o formato padrão é PDF se não houver seleção.
- [ ] AC4: A pasta **"Pronto Profe"** é criada automaticamente na raiz do Drive/OneDrive se não existir.
- [ ] AC5: Dentro de "Pronto Profe", uma subpasta **"Mês Ano"** (ex: "Abril 2026") é criada automaticamente se não existir.
- [ ] AC6: O arquivo é salvo na subpasta correta com o nome `pronto-profe-YYYY-MM-DD.{ext}`.
- [ ] AC7: Após salvar, exibe mensagem de confirmação com link direto para o arquivo na nuvem.
- [ ] AC8: Em caso de erro (sem permissão, offline, token expirado), exibe mensagem clara e sugere tentar novamente ou usar download local.
- [ ] AC9: O token OAuth é mantido na sessão (não persiste após fechar o browser por segurança).
- [ ] AC10: O escopo de permissão é mínimo — acesso **apenas aos arquivos criados pelo app** (`drive.file` no Google, `Files.ReadWrite.AppFolder` no OneDrive).

## Notas Técnicas

### Google Drive

```
Autenticação: Google Identity Services (GIS) — script via CDN
Lib Drive:    gapi.client.drive (Google API Client Library)
Escopo:       https://www.googleapis.com/auth/drive.file
              (acesso apenas a arquivos criados pelo app — não vê o restante do Drive)
Criar pasta:  files.create({ mimeType: 'application/vnd.google-apps.folder', name, parents })
Upload:       files.create({ multipart: true }, metadata + blob)
```

### OneDrive / Microsoft Graph

```
Autenticação: @microsoft/msal-browser (MSAL.js 2.x)
Escopo:       Files.ReadWrite.AppFolder
              (pasta isolada "Aplicativos/Pronto Profe" no OneDrive do usuário)
Criar pasta:  PUT /me/drive/root:/Pronto Profe/Abril 2026:/children (com body folder:{})
Upload:       PUT /me/drive/root:/Pronto Profe/Abril 2026/arquivo.pdf:/content
```

### Variáveis de Ambiente Necessárias

```env
NEXT_PUBLIC_GOOGLE_CLIENT_ID=xxxx.apps.googleusercontent.com
NEXT_PUBLIC_ONEDRIVE_CLIENT_ID=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```

### Estrutura de Pastas Automática

```
Pronto Profe/               ← criada na 1ª autenticação
  └── Abril 2026/           ← criada no 1º save do mês
      └── pronto-profe-2026-04-15.pdf
```
